# Franzen Duck · просмотр траекторий

[Открыть демо](https://iameteron.github.io/franzen-duck-replay/)

Два записанных победных прохождения публичных игр ARC-AGI-3 дообученной моделью Qwen Flash-Next в харнессе Franzen Duck. Использован адаптер LoRA rank 64, checkpoint 312, обученный с окном 32K. Обе игры входили в обучающий набор на других траекториях.

| Игра | Уровни | Действия | Ответы модели |
|---|---:|---:|---:|
| SB26 | 8 | 137 | 44 |
| TR87 | 6 | 351 | 76 |

Стрелки ← и → переключают шаги и действия внутри серии. Shift + стрелка переключает целые окна. Можно выбрать уровень, передвинуть ползунок или скопировать адрес текущего шага. Длинный текст прокручивается внутри окна. Нажатие на строку компоненты подсвечивает соответствующий объект. Янтарный контур обозначает клетки, изменившиеся с предыдущего игрового кадра.

В одном вызове TR87 есть 42 действия без отдельных строк в выводе Python. Для них используются последовательные кадры и названия действий из записи среды.

Демо работает как статический сайт. Для локального просмотра запустите в каталоге проекта `python3 -m http.server 8000` и откройте `http://localhost:8000`.
