# AA3 Replay · просмотр траекторий

[Открыть демо](https://iameteron.github.io/aa3-replay/)

В демо собраны четыре победных прохождения. Для [SB26](https://iameteron.github.io/aa3-replay/#sb26/1) и [TR87](https://iameteron.github.io/aa3-replay/#tr87/1) в обучающем наборе были другие траектории тех же игр.

Прохождения [AR25](https://iameteron.github.io/aa3-replay/#ar25/1) (публичная игра, seed 202610040) и [Glyph Sudoku](https://iameteron.github.io/aa3-replay/#glyph_sudoku/1) (сгенерированная игра Forge, seed 202610093) записаны в ML Space.

| Игра | Уровни | Действия | Ответы модели |
|---|---:|---:|---:|
| SB26 | 8 | 137 | 44 |
| TR87 | 6 | 351 | 76 |
| AR25 | 8 | 387 | 132 |
| Glyph Sudoku | 4 | 71 | 26 |

Стрелки ← и → переключают шаги и действия внутри серии. Shift + стрелка переключает целые окна. Можно выбрать уровень, передвинуть ползунок или скопировать адрес текущего шага. Длинный текст прокручивается внутри окна. Нажатие на строку компоненты подсвечивает соответствующий объект. Янтарный контур обозначает клетки, изменившиеся с предыдущего игрового кадра.

В одном вызове TR87 есть 42 действия без отдельных строк в выводе Python. В AR25 четыре вызова Python завершились по тайм-ауту после 86 выполненных действий. Для этих шагов используются последовательные кадры и названия действий из записи среды.

Демо работает как статический сайт. Для локального просмотра запустите в каталоге проекта `python3 -m http.server 8000` и откройте `http://localhost:8000`.
